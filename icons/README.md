# Icons

SVG icons for Dis nos horaires. `src/styles/global.css` imports them, so the build puts them into the CSS. The style rules are in `style-spec.json`. `preview.html` shows all
icons.

All icons use `stroke="currentColor"`, the logo `fill="currentColor"`. Set the color with the CSS `color` property.

| Icon                                | File                | Use                                                                   |
| ----------------------------------- | ------------------- | --------------------------------------------------------------------- |
| ![map-pin](map-pin.svg)             | `map-pin.svg`       | "Plan" link of a theater. Opens a Google Maps search for its address. |
| ![external-link](external-link.svg) | `external-link.svg` | Link to an external site (IMDb, Letterboxd).                          |
| ![info](info.svg)                   | `info.svg`          | Opens the card of a film: its ratings and a frame.                    |
| ![close](close.svg)                 | `close.svg`         | Closes the frame of the film.                                         |
| ![arrow-right](arrow-right.svg)     | `arrow-right.svg`   | Opens the city that matches the search on the root page.              |
| ![swap](swap.svg)                   | `swap.svg`          | Follows the city name in the day bar: opens the city picker.          |
| ![github](github.svg)               | `github.svg`        | Footer link to the GitHub repository.                                 |
| ![instagram](instagram.svg)         | `instagram.svg`     | Footer link to the Instagram account.                                 |
| ![mail](mail.svg)                   | `mail.svg`          | Footer link to the email address.                                     |
| ![logo](logo.svg)                   | `logo.svg`          | The dinosaur before the name of the site.                             |
